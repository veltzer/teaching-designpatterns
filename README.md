# teaching-designpatterns

Demos and exercises for design patterns.

- `Design_Exercises.md` - design situations to match to a pattern.
- `Identify_the_patterns.md` - spot the pattern in the given code.
- `Implementation.md` - implementation exercises.
- `design-patterns-exercises/` - the Java project for the exercises
  (also packaged as `DesignPatternsExercise.zip`).
